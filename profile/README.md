# zenoku-dev

Домашняя self-hosted инфраструктура и инструменты, которые говорят, что они делают.
Всё на своём железе: свои данные, свои ключи, свои правила.

| Репо | Что делает |
|---|---|
| [zeno](https://github.com/Zenoku-Dev/zeno) | локальный аналог VirusTotal: хэши по открытым базам, движки ClamAV / YARA-X |
| [zent](https://github.com/Zenoku-Dev/zent) | «Zenoku Post»: свой SMTP/POP3/IMAP на Rust, антиспам-нейронка |
| [auth](https://github.com/Zenoku-Dev/auth) | rival-auth: единая авторизация — HTTP API, JWT/HMAC, SSH-шлюз |
| [rsh](https://github.com/Zenoku-Dev/rsh) | удалённая оболочка: rsh идут через auth → VPS → туннель к узлу |
| [zenoku-design](https://github.com/Zenoku-Dev/zenoku-design) | знаки и бренд-гайдлайны: zenoku, zeno, zent, rsh, auth, zenoku-dev |

Монохром, один язык штриха, один акцент. Подробности — в [DESIGN.md](https://github.com/Zenoku-Dev/zenoku-design/blob/main/DESIGN.md).
